# 变更日志

本文档记录 ooderNexus Enterprise 的所有重要变更。

---

## [3.0.2] - 2026-04-07

### 新增

- ✨ 创建 MIT 开源版本
- ✨ 内置核心驱动: SPI, LLM Base, RAG, Org Web
- ✨ 内置必需系统服务: Auth, Config, Discovery, Install, Menu
- ✨ 支持 Gitee 发现机制动态安装应用
- ✨ 提供完整的开源文档

### 变更

- 🔄 从完整版本精简为最小化开源版本
- 🔄 移除非必需业务模块(可通过 Gitee 安装)
- 🔄 移除所有敏感配置信息

### 优化

- ⚡ 减小安装包体积
- ⚡ 提升启动速度
- ⚡ 优化内存占用
